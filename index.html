NAZE AI

Think. Create. Solve.

NAZE AI adalah asisten AI untuk chat, membaca gambar, menganalisis dokumen teks, dan membantu coding — didukung oleh Google Gemini API (tier gratis).

Arsitektur & keamanan: permintaan diproses melalui koneksi terkelola sehingga API key tidak pernah tersimpan atau terlihat di kode frontend.

Yang bisa dibaca langsung:

  • Gambar: JPG, PNG, WEBP, GIF (vision)
  • Teks/kode: TXT, CSV, JSON, MD, dan file source code

Belum didukung di browser: ekstraksi isi PDF, DOCX, XLSX, PPTX — file jenis ini akan ditandai, bukan dibaca diam-diam, agar jawaban NAZE tetap jujur.

PWA: app shell di-cache oleh service worker agar tampilan tetap terbuka saat offline, dan bisa dipasang ke homescreen. Prompt "Pasang Aplikasi" hanya muncul jika browser mendukungnya dan file ini disajikan lewat hosting HTTPS sungguhan (bukan pratinjau sandbox ini).
